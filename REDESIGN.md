# FMD OS — веб-редизайн

## Концепция

Веб-интерфейс переведён в визуальную систему **FMD OS**: приватный инструментальный dashboard для быстрого поиска и управления устройством. Основной язык интерфейса — плотная telemetry-композиция с графитовым фоном, signal-green акцентом, моноширинными координатами, карточками статуса и картой как главным рабочим пространством.

Редизайн выполнен поверх существующей архитектуры React/Vite и сохраняет текущий API, шифрование, 2FA, модальные окна, фотогалерею, Leaflet-карту и серверные команды.

## Проверка

`pnpm run type-check`, `pnpm run build` и `go test ./...` проходят. Vite всё ещё сообщает предупреждения о legacy `theme-init.js`, Leaflet dynamic import и размере чанка — это не блокирует сборку. `pnpm run lint` в исходной конфигурации требует обновления совместимости между `typescript-eslint` и TypeScript 7.0.2; эта проблема не связана с кодом редизайна.

## Android-этап

После получения Android-проекта следует перенести ту же модель навигации: обзор устройства, история, центр команд, экспорт/шаринг и локальные избранные точки. Для Android желательно сохранить единые названия команд и цветовые токены FMD OS, а мобильную нижнюю навигацию веб-версии использовать как основу для Material-навигации приложения.
